# Text Summarization AI

An AI-powered text summarization application built with Python, FastAPI, React, TypeScript, NLP, and transformer-based language models.

## Features

- Upload TXT, PDF, or DOCX documents
- Paste text directly into the application
- Generate AI-powered summaries
- Select summary length
- View key takeaways
- Display original and summarized word counts
- Calculate compression percentage
- Track processing latency
- Recruiter-ready web interface

## Architecture

React + TypeScript frontend  
↓  
FastAPI backend  
↓  
Python NLP processing  
↓  
AI summarization model
